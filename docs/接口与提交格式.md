# 接口与提交格式

从`Transformer_low/`运行命令；代码写在`basics/`，补全`tests/adapters.py`的21个适配函数和`course_entry.py`的三个接口。

## 速查表

| 项目 | 要求 |
|---|---|
| `train(config, run_dir, resume=None)` | 从零训练或恢复；保存实际配置、每步CSV、验证和checkpoint |
| `load_model(checkpoint, config)` | 加载评分权重或完整checkpoint；返回模型，整数`[B,T]`输入→`[B,T,10000]` logits |
| `export(checkpoint, output)` | 导出单一checkpoint的完整CPU FP32 `state_dict`，≤240 MB |
| 环境 | Linux、Python 3.12.14、PyTorch 2.11.0＋CUDA 12.8及课程`uv.lock` |
| 正式运行 | `format_version=2`、`track=low`、`mode=ranked`；40,960,000目标token |
| 每次实验文件 | `config.json`、`metrics.csv`、`curve.png`；目录名作运行编号 |
| 第一阶段 | 网页填写结构、环境等信息，只上传评分权重 |
| 第二阶段 | 代码（含环境文件）＋每次必做训练实验的三个文件，普通ZIP≤250 MB |

大小均按十进制字节计算。无需另交报告、README、测试/生成输出或自检报告。模型与材料分别验收，归档不等于代码执行通过。

## CSV八个字段

| 字段 | 内容 |
|---|---|
| `event` | `train`或`valid` |
| `step` | 已完成的更新次数 |
| `train_tokens` | 累计训练目标token |
| `train_loss` | 本次更新按目标数加权的训练NLL；valid行可空 |
| `valid_nll` | 完整公开验证NLL；train行留空 |
| `valid_ppl` | exp(valid_nll)；train行留空 |
| `lr` | 本次或最近一次更新使用的学习率 |
| `elapsed_seconds` | 本次运行累计耗时，单位秒 |

每步写train行，每4,096,000目标token写valid行。UTF-8 CSV，保留原始精度；空值留空，NaN/Inf如实记录，失败运行保留到停止处。其他列可选。绘图命令：

```bash
uv run --frozen python -m course_tools.plot_logs runs/final
```

<details>
<summary>模型结构与导出键名（实现时查看）</summary>

允许调整层数L、隐藏维度d、头数、FFN维度f；d能被头数整除，RoPE每头维度为偶数。`norm=pre/post/none`，`position=rope/none`，`ffn=swiglu/silu`。全部参数（含冻结参数）≤50,000,000。

固定10,000词课程BPE、256上下文、因果多头注意力、无bias、输入输出嵌入不共享；RoPE theta=10000、RMSNorm epsilon=1e-5。Pre在Attention/FFN前归一化，再加残差；Post先加残差，再归一化。pre/post均保留最终RMSNorm；none不使用RMSNorm。

RoPE旋转相邻偶/奇坐标，每窗位置从0开始，头沿输出维按head顺序排列。SwiGLU为`w2(SiLU(w1x) * w3x)`，SiLU为`w2(SiLU(w1x))`；提供的SiLU消融配置使用f=4d。

| 导出键名（i=0…L−1） | 形状 |
|---|---|
| `token_embeddings.weight`、`lm_head.weight` | 各[10000,d] |
| `layers.i.attn.q_proj.weight` / `k_proj.weight` / `v_proj.weight` / `output_proj.weight` | 各[d,d] |
| `layers.i.ln1.weight`、`layers.i.ln2.weight` | 各[d]；norm不是none时存在 |
| `layers.i.ffn.w1.weight` | [f,d] |
| `layers.i.ffn.w3.weight` | [f,d]；仅SwiGLU存在 |
| `layers.i.ffn.w2.weight` | [d,f] |
| `ln_final.weight` | [d]；norm不是none时存在 |

`course_tools.contracts.expected_shapes(config["model"])`生成完整键名。张量须独立紧凑存储：`.detach().cpu().float().contiguous().clone()`，用默认`torch.save(state_dict, path)`保存。不带额外buffer、自定义对象或优化器。

<details>
<summary>实际配置、验证与恢复（训练时查看）</summary>

沿用`configs/baseline.json`字段，保存实际seed、模型、优化器、学习率、batch、精度和数据路径。评分所需模型规格由网页填写产生，不含学习率等训练参数；第二阶段的`config.json`须记录完整实际训练配置，结构与已验收模型一致。

`train`支持ranked正式运行、experiment对比实验及smoke短测试。有效batch=micro batch×梯度累积；预算、验证和checkpoint边界落在完整更新后。smoke前向的词表与维度取配置值。

公开验证使用FP32，关闭autocast和TF32；固定token流，窗口/步长256，目标右移一位，计入EOS与尾部。公开有效目标共387,710个。NLL=loss总和/目标数，PPL=exp(NLL)，不能平均batch的PPL。同环境复评NLL误差≤1e-5。

保存公开NLL最低状态为`best.pt`，另存0/20/60/100%完整恢复状态。包括模型、优化器、调度进度、step/token计数、配置、Python/NumPy/Torch/CUDA和数据采样随机状态，以及启用时的AMP scaler。用Tensor、数值、字符串和普通容器保存；恢复后保留日志与最优状态，不重复计数。全部过程checkpoint自留，需要核验时再提供。

```bash
uv run --frozen python course_entry.py train --config runs/final/config.json \
  --run-dir runs/final_resumed --resume runs/final/checkpoint_020.pt
```
