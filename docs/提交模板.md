# 材料目录示例

此页仅供参考，无需填写或提交。

**第一阶段**：在网页填写信息，只上传`final.weights.pt`（≤240 MB）。

**第二阶段**：模型验收通过后上传普通ZIP（≤250 MB），只包含代码和每次必做训练实验的三个文件：

```text
作业材料/
├── course_entry.py
├── basics/                  # 全部实现代码
├── tests/                   # 含补全的 adapters.py
├── course_tools/            # 代码依赖的课程工具
├── pyproject.toml
├── uv.lock
├── .python-version
└── runs/
    ├── final/               # 须与网页填写的最终实验目录名一致
    │   ├── config.json      # 实际完整训练配置
    │   ├── metrics.csv      # 完整训练和公开验证日志
    │   └── curve.png        # 从该CSV生成
    ├── lr_0003/             # 其余目录均包含同样三个文件
    ├── lr_003/
    ├── batch_16/
    ├── batch_64/
    ├── no_rmsnorm/
    ├── post_norm/
    ├── no_rope/
    └── silu/
```

示例假设`final`同时作为学习率0.001、有效batch32的基准，因此合计覆盖3个学习率、3个batch与4项消融。目录名可以自定，若最终模型来自其他实验，在网页填写那个目录名即可。

不放数据、权重、checkpoint、虚拟环境和缓存；不另交报告、README、测试输出、生成样例、自检报告或JSONL。过程checkpoint自行保管，需要核验时再提供。

真实的三个文件可参考[`examples/low_base_lr003_seed3362027/`](../examples/low_base_lr003_seed3362027/)，请提交自己的实验记录。
